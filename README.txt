BOYFRIEND DAY — VINTAGE SCRAPBOOK
===================================

Files:
index.html        = Home
memories.html     = photo scrapbook
letters.html      = clickable letters
open-when.html    = interactive surprise cards
miles.html        = long-distance page + playlist
special.html      = final Boyfriend Day surprise
song.html         = dedicated song page
forever.html      = YES / NO forever question
style.css         = vintage scrapbook design
script.js         = interactions
images/           = put your photos here

TODAY'S QUICK CUSTOMISATION:
1. Open index.html and change the small messages if you want.
2. Open memories.html and replace each "YOUR PHOTO" placeholder later.
3. Open miles.html and replace "your city"/"my city".
4. In script.js, edit the letter and surprise text if you want.
5. Open special.html and personalise the final letter.
6. Test index.html in your browser.
7. Upload the whole folder to GitHub Pages.

PHOTO TIP:
Put photos inside images/ and replace a placeholder div in memories.html with:
<img src="images/photo1.jpg" alt="Our memory">

GITHUB PAGES:
Create a GitHub repository (for example: boyfriend-day).
Upload ALL files/folders.
Settings -> Pages -> Deploy from a branch -> main -> / (root) -> Save.
Wait for the Pages URL, then send that URL to Baby.

No paid software is required.

NEW FEATURES:
- forever.html has YES/NO. NO opens a playful HOW DARE YOU page with DO AGAIN.
- song.html has a real audio player. Add your own song.mp3 to this folder.
- Browser autoplay is intentionally not forced; the user taps Play, which works more reliably.
